# Protocol Versions

Version domains are independent:

| Domain | Initial status |
|---|---|
| Application | `0.1.0` scaffold |
| Circuit Schema | `1.0` |
| Hardware RPC | `0.1-dev` |
| FPGA Protocol | `0.1-dev` |
| FPGA Register Map | `0.1-dev` |

Do not derive one version from another automatically.
