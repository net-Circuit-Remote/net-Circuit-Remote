# End-to-End Tests

Initial target scenarios:

1. two switches -> 74HC08 -> LED;
2. virtual clock -> sequential device;
3. virtual capture -> waveform return;
4. later, the same tests against an explicitly selected Physical Hardware Station.

No physical FPGA is required for the initial CI scaffold.
