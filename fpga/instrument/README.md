# Instrument Domain

Reserved for future EP4CE10 V1 instrument RTL:

- Trigger Engine
- Logic Analyzer
- Generator
- acquisition path for oscilloscope-class measurements
- capture buffering
- SDR SDRAM controller/arbiter

**Status:** not implemented.

Analog oscilloscope functionality will require external ADC/analog front-end hardware. Analog/arbitrary waveform generation may require DAC/output circuitry. Exact parts are not selected.
