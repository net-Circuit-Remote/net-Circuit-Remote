## Implementation

`apps/web/src/App.vue` renders one workbench; compatibility routing redirects to `/`. New workbench/window/scene/files modules replace the seven old pages and five old permanent-panel/dock components. The six stores and existing transport boundary remain.

Seventeen supplied SVG icons are consumed through small committed derivatives generated by `scripts/prepare_workbench_icons.py`. Their manifest verifies unchanged original artwork. Updated npm runtime tests, frontend Python checks and CI triggers cover the migration. Phase 2 circuit editing and execution remain separate work.
